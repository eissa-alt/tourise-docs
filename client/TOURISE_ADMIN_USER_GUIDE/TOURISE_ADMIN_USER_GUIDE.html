Using the Admin Panel

The everyday jobs in the TOURISE 2027 admin, in short: reviewing guests, sending invitations, and running the event on site. Screens and wording as of 21 September 2026.

Getting in

Sign inEmail and password, then enter the code emailed to you and select Verify now. No code? Wait for the countdown, select Resend, and check spam. Forgot your password? sends a reset link.
LanguageEnglish or Arabic, from the switch in the top bar. Arabic switches the layout to right-to-left.
What you seeYour role decides which screens are in your menu. Your data scope decides which guests you see. If a screen is missing or your guest list is empty, ask a Super Admin.

The dashboard

It shows live registration figures: key totals, the daily trend, status by category, the audience profile, and invitations and requests.

  • The filters at the top (category, seniority, status, region, industry, date) apply to every figure.
  • Click any bar or slice to filter by it. Click it again to clear.
  • Print report prints the page as a landscape report, stamped with the time.

Invitations

Inviting guests

Private categories (Dignitary, VIP, Speaker and others) need an invitation. There are three ways a guest gets one.

1You send it  Overview → Invitations

  1. Select New invitation, name the collection and choose its category.
  2. Pick the channel (email, SMS or WhatsApp) and the template. An email template must include {{ invitation_link }}.
  3. Choose the usage: Single gives one link per person. Multiple gives one shared link with a set number of uses.
  4. Add guests manually or by Excel upload. You can also turn on Prefill data and Lock data.
  5. Save, then select Send invitation, or Send in bulk for the whole collection.

2They request it  Overview → Invitation Requests

Requests from the website and from partner sites wait in a queue.

  • Accept invites the person to the target category, or adds them to it directly.
  • Reject sends the rejection email if one is set. Otherwise the person is told nothing.
  • Move to category… redirects one request.
  • Each request category's form, target, emails and OTP are set under Request categories.
Partner API keys

Each partner site gets its own key under Operations → API keys. A key is shown only once, so copy it straight away. If it's lost, issue a new one.

3A dignitary names them  Overview → Dignitary Parties

Step 1The dignitary registers and lists their party
→
Step 2Each person is emailed a personal, single-use invitation
→
Step 3Their form opens pre-filled and linked to the dignitary
→
Step 4They register as Invited, under the dignitary's party

Delegation, Security and Protocol are separate categories, and a dignitary can add up to 30 people. No one on the team creates or forwards links. The screen lists each dignitary's people, who has registered, and each email's state. Use Send / Resend, Invite someone for anyone left out, and Invitation email to choose the template. In Guests, a party member's row shows Invited by and the dignitary's name.

Do this first

Choose the Invitation email on Dignitary Parties. Until you do, party invitations are created but not emailed.

Setup & operations

Setting up and running the event

Categories  Management → Categories

Every guest belongs to a category. It decides the form, who may register, the guest's status and which messages go out.

General settings *Names, slug and visibility. Private needs an invitation. Public is an open link. Also sets the status given on register, accept and reject.
Form configuration *The form shape and its mandatory fields.
CommunicationsThe email, SMS and WhatsApp templates sent on register, accept, reject and decline.
Success page · ExtrasThe page shown after submitting, plus e-badge, QR code, OTP, extra guests and onboarding.
Admin accessAdds this category to scoped admins' access in one step.

* required  ·  Clone a similar category to start faster.  ·  Block takes a category out of use, and Activate brings it back.

Access

Admins and troubleshooting

Adding an admin  Management → Admins

  1. Select New admin and enter their name, email and phone.
  2. Choose a role, which decides what they can do. Roles are shared, so create a new role rather than widening an existing one.
  3. Select Send setup email (recommended), and keep Require OTP on login on.
  4. Set the data scope: categories, statuses, and an area or gate for on-site staff.
  5. Ask them to sign in and check that their guest list is what you expect.
An empty scope shows no guests

A non-Super admin with no categories and no statuses sees no guests. The hint on the admin form currently says the opposite. Categories and statuses combine: Sponsor + Accepted shows accepted sponsors only.

The full permission matrix is in the separate Administrator Access & Roles guide.
